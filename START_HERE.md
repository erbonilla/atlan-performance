## 🆘 Si Necesitas Ayuda

### Durante el Setup
- 📖 Consulta: `DEPLOYMENT_GUIDE.md` (sección Troubleshooting)
- 🌐 Vercel Docs: https://vercel.com/docs

### Problemas Comunes

**Build falla:**
- Verifica que las variables de entorno estén correctas
- Revisa los logs en Vercel Dashboard

**Formularios no funcionan:**
- Asegúrate de haber agregado las variables de Supabase
- Verifica CORS en Supabase Dashboard

**Rutas dan 404:**
- Verifica que `vercel.json` esté en la raíz
- Haz redeploy desde Vercel
